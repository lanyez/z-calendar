# Z日历（任务栏日历，Rust 版）

替换 Windows 任务栏"点击时间弹出日历"的日历应用，Rust 原生实现（GDI+ 自绘渲染，无 GPU 框架），编译为**单个约 1.9MB 的独立 exe**，无任何运行时依赖，**常驻内存极低：隐藏态提交内存约 4MB / 工作集约 1MB，显示日历时约 6MB**（后台位图隐藏即释放、显示时惰性重建），可直接拷贝到任意目录运行。

## 功能

- **接管任务栏时钟**（Windows 10 / 11）：通过低级鼠标钩子（WH_MOUSE_LL）拦截对任务栏时钟的点击并弹出本日历（点击被吞掉，系统日历不会再弹出；右键时钟弹出菜单：软件设置 / 开机自启（开启时左侧打勾）/ 日期与时间（打开系统设置）/ 退出Z日历）。不建窗口、不遮挡、不修改原生时钟，时钟样式与悬停效果保持系统原样；全屏应用时自动放行，退出软件自动移除钩子。
- **纯后台运行**：日历弹窗带 `WS_EX_TOOLWINDOW`，任务栏和 Alt-Tab 中不出现程序；常驻入口只有托盘图标。
- **法定节假日自动对接**：数据来自 [chinese-days](https://github.com/yaavi/chinese-days)（`cdn.jsdelivr.net/npm/chinese-days/dist/holidays.ics`），法定节假日"休"（蓝角标）与调休补班"班"（红角标）。启动及每 30 分钟检查一次，距上次成功更新超过 12 小时自动重新拉取（约每天一次），缓存到本地；数据源每年发布新年份数据后自动跟进（当前覆盖 2024~2026）。
- **农历 / 节气 / 节日**：内置 1900~2100 农历与二十四节气数据表（由 lunar-javascript 数据一次性生成，见 `rust/gen-lunar.js`），传统节日（春节/除夕红色）、公历节日、纪念日（烈士纪念日等红色）本地计算，离线可用。
- **周数**：左侧 ISO 周数列（可在设置中关闭）、**今日蓝色圆形高亮**、非本月日期置灰（可选择隐藏）。
- **天气**：头部右上角展示当前温度与天气现象（位置与原设计一致），**鼠标悬停在日历左侧弹出近 7 天天气预报并保持常驻**（鼠标移开不关闭，日历关闭或打开设置窗口时收起；面板紧贴日历左侧、顶部与日历对齐，均无边框；城市名简体中文显示；含天气现象/温度范围/空气质量 US AQI，AQI 数据源仅覆盖未来 5 天，之后显示"空气 --"；头部显示"更新时间：HH:MM"，"更新"为手动刷新链接（悬停变手型变白，无下划线），点击立即拉取，刷新期间显示"更新中…"并防连点）。定位主用 ip-api.com（大陆准确、中文城市名），失败回退 ipwho.is + BigDataCloud 反向地理编码；天气相关请求均 **IPv4 优先解析**（电信等运营商的 IPv6 出口在 IP 定位库中常被错标城市，如广东电信 IPv6 被标到海南儋州），主定位超时自动重试一次；天气与空气质量来自 Open-Meteo。每小时自动刷新，失败 1 分钟后重试，失败自动隐藏；本地缓存 3 小时。
- **日程**：按选中日期增删日程（本地存储），支持中文 IME 与剪贴板粘贴输入，有日程的日期左上角显示蓝点（有待办的日期并排显示橙点）；日程页条目过多时滚轮滚动查看，点击条目打开编辑弹窗（旧纯文本条目转为富条目编辑），底部快捷输入直接回车新增——输入"14:30 项目评审""9:00-10:00 晨会""9点 开会"这类带时间的文本会自动解析出时间直接生成带时间的日程（支持 `HH:MM`、`H点`、`H点半`、`H点M分` 及 `-`/`~` 时间区间；解析不出时间则按旧纯文本条目保存）。
- **提醒与重复**：日程/待办的"提醒"（准时/提前分钟数）由后台线程每 20 秒扫描，到期后右下角弹出提醒卡片并伴随提示音（系统"感叹号"音，可在设置中关闭；不抢焦点，10 秒自动消失，最多同时 3 条）；提醒卡片带操作按钮——待办提醒可「完成」（重复待办按当天记录完成），所有提醒可「稍后10分钟」（登记到 `snooze.json`，10 分钟后自动补提，可反复推迟）；点击卡片其他区域打开日历；错过提醒时点 2 分钟内补提一次，已提醒档期登记到 `remind_done.json`（重启不重提，7 天后清理）。重复分两级——分钟级"每 5/15/30/60 分钟"从提醒时点起按间隔重复提醒直到结束时间（无结束时间按开始后 1 小时）；按天级"每天 / 每周 / 每月 / 每年 / 农历每年"在日程页、侧栏"今日日程"、月历蓝点角标和提醒扫描中按规则展开（条目带 ↻ 标记，每次出现单独提醒；农历每年按农历月/日比对，闰月里的日子按普通月处理；每次出现当天已完成的重复待办不再提醒）；编辑重复条目时可选「修改范围」（整个系列 / 仅这一天——"仅这一天"会把当天从系列中排除并另存一条独立条目）；可设「重复至」某日（含当天，默认无限重复）；✕ 删除重复条目时弹出选择菜单「仅删除这一天 / 删除整个系列」；全天日程按 09:00 计算提醒时点。
- **数据自愈**：`agenda.json` / `todo.json` / `remind_done.json` / `snooze.json` 读取发现损坏时自动从上次写入的 `.bak` 备份恢复并弹提醒卡片告知；坏文件留档为 `.corrupt`（即使没有可用备份也会改名，避免下次保存把坏内容复制进 `.bak`）。
- **右键日期**：弹出菜单"新增日程 / 新增待办"，打开完整表单弹窗（打开时日历保持显示）；左键点击任意位置可关闭菜单。
  - **新增待办**：待办内容（多行文本）、优先级下拉（默认"不选"；Ⅰ重要且紧急 / Ⅱ重要但不紧急 / Ⅲ紧急但不重要 / Ⅳ不重要不紧急，罗马数字彩色图标）、时间开关（关闭时隐藏后续项）、开始/结束（两步选择：先月历选日期，再"下一步"进时/分列表选时间，精确到分；全天日程只有日期一步）、提醒（不提醒/准时/5分钟前/15分钟前/30分钟前/1小时前/1天前）、重复（单次/每5/15/30/60分钟/每天/每周/每月/每年/农历每年，分钟级与按天级互斥；按天重复即使不开时间也生效，完成按"日子"记录）；选了按天重复时出现「重复至」开关与日期选择（默认无限重复），编辑已有重复待办时还出现「修改范围」（整个系列 / 仅这一天）。
  - **新增日程**：日程名称、全天开关（开启只选日期，关闭选日期时间）、开始/结束、提醒、重复（范围/重复至选项与待办一致）。
  - 弹窗支持中文 IME、剪贴板粘贴、标题栏拖动；Esc 取消（有下拉/面板时先收起）、日程回车保存、待办 Ctrl+Enter 保存。保存后日程（含时间/全天前缀）显示在日程页与侧栏"今日日程"，待办按优先级色点显示在侧栏"待办清单"。
  - **日历格节日名**：假期每一天都显示节日/假日名称（此前超过 4 天的假期只有第一天显示）；名称统一为鲜艳蓝色；5 字内名称自适应缩小字号完整显示（如"烈士纪念日"），超过 5 字分两行。本月工作日日期为纯白高对比，周末保持红色。
- **今天的圆圈**：蓝色圆圈同时圈住数字日期与农历/节日行（宽度按文本自适应，农历在圆内显示为白色）。
- **非当前月日期行**：显示非当前月日期开启时固定 6 行（含与当前月相邻的上一周/下一周）；关闭时只保留包含当月日期的行，行高自动变大补满日历（窗口高度不变）。
- **日期侧边栏**：点击日历日期时在日历左侧弹出详情侧栏（紧贴、顶部对齐、点击侧栏不关闭日历），再次点击同一日期收起；卡片包括日期信息（第N天/第N周/星座/农历干支）、黄历信息（建除十二神宜忌+日冲煞）、最近事件（下一个法定假日倒计时）、今日日程（点击条目行或 ✎ 打开编辑弹窗，✕ 删除——重复日程弹「仅删除这一天 / 删除整个系列」选择菜单；超过 5 条滚轮滚动）、历史上的今天（内置精选事件库）、时间格言（一言 API hitokoto.cn，按分类拉取：名人名言/文学/互联网/科普；不缓存，每次点击日期都重新获取一条，新的一条返回前沿用上一条，失败时回退内置格言）、待办清单（todo.json，按"带时间的时间升序 → 无时间 → 优先级（收集箱垫底）"排序，点击圆圈切换完成（按天重复的按当天记录），✎ 编辑、✕ 删除——重复待办同样弹「仅这一天 / 整个系列」菜单；今天视角下卡片顶部列出逾期待办：红字带原日期，"→"一键顺延到今天；右上角"清除已完成"一键清空；超过 5 条滚轮滚动）；卡片显示顺序可在设置中拖动调整；底部"卡片管理"直达设置对应页签。侧栏采用 NOACTIVATE+MA_NOACTIVATE，与主日历失焦联动逻辑一致。
- **设置窗口**：三个页签——软件设置（开机自启、自动更新假期数据、显示系统托盘图标）、日历设置（显示天气预报、使用 12 小时制（同时作用于日程/待办/提醒卡片的时间显示）、显示周数、显示农历/节日信息、显示调休安排、显示非当前月日期、提醒提示音、一周开始）、侧栏管理（日期信息、黄历信息、最近事件、今日日程、历史上的今天、时间格言、待办清单 7 张卡片开关，**拖动卡片行可调整侧栏显示顺序**，时间格言下方为格言类型下拉：名人名言/文学/互联网/科普），更改立即生效无需保存。
- **托盘**常驻（显示日历 / 开机自启 / 立即更新节假日数据 / 退出），单实例运行。

## 使用

- 启动：运行 `rust/target/release/z-calendar.exe`（纯 GUI 程序无控制台），可自行复制改名（如 `Z日历.exe`）到任意位置。
- 点击任务栏右下角时间 → 弹出日历；再点一次时钟 / Esc / 点击日历外任意位置 → 关闭。
- 鼠标悬停头部右上角天气（图标/温度）→ 日历左侧弹出近一周天气面板，常驻显示；关闭日历或打开设置窗口时收起。
- 应用已在运行时再次启动 → 已运行实例的日历自动弹出（单实例，无重复进程）。
- 开机自启：托盘菜单或设置中勾选（写注册表 `HKCU\...\Run`，项名「Z日历」，指向当前 exe 路径）。
- 月份标题点击回到今天；‹ › 切换月份；底部工具条：日程 / 今天 / ＋ / 设置 / 退出。

## 构建

```cmd
cd rust
build.cmd          REM 将 E:\tools\mingw64\bin 加入 PATH 后执行 cargo build --release 与 cargo test
```

- 工具链：stable-x86_64-pc-windows-gnu（rustup 默认）+ [MinGW-w64](https://winlibs.com)（gcc，位于 `E:\tools\mingw64`，构建 `ring` 等需要）。
- 产物：`rust/target/release/z-calendar.exe`（约 1.9MB，静态链接 CRT/pthread，可直接拷贝运行）。
- **图标**：构建时以 `rust/icon.png` 为源自动生成多尺寸 `icon.ico`（16~256px）嵌入 exe，托盘图标与 exe 图标同源；换图标只需替换 `icon.png` 后重新构建。
- `cargo test` 内置农历转换/节气/节日单元测试与天气联网测试。

## 数据与配置

配置与缓存均在 `%APPDATA%\z-calendar\`：

- `config.json` — 配置项
- `holidays.json` — 法定节假日缓存
- `weather.json` — 天气缓存（3 小时有效）
- `agenda.json` — 日程（新条目为对象：名称/全天/起止/提醒/重复（分钟级）/按天重复 recur（d/w/m/y/l）/重复至 recur_until/仅此次例外 skip_dates；旧纯文本条目自动兼容，编辑后转为富条目）
- `todo.json` — 待办（文本/完成/日期 + 优先级/时间/提醒/重复/按天重复/完成记录 done_dates/重复至/仅此次例外可选字段）
- `remind_done.json` — 已提醒档期登记（防止重启后重复提醒，7 天后自动清理）
- `snooze.json` — 提醒卡片「稍后10分钟」登记（到点由提醒线程补发）
- `agenda.bak` / `todo.bak` / `remind_done.bak` / `snooze.bak` — 各数据文件写入前的自动备份；数据文件损坏时**启动/读取自动从 `.bak` 恢复**并弹提醒卡片告知，坏文件留档为 `.corrupt`（也可手工把 `.bak` 改回 `.json` 恢复）

## 实现要点

- 时钟定位：Win10 走经典窗口链 `Shell_TrayWnd → TrayNotifyWnd → TrayClockWClass`；Win11 任务栏时钟是 XAML 渲染、没有对应 Win32 子窗口，由独立 UIA 定位线程（`src/uia_clock.rs`，winapi 无 UIA 绑定，手写最小 COM 声明）在 `Shell_TrayWnd` 子树里找"UIA Name 是日期时间文本"的元素、取最右者得到时钟矩形。每秒校正，经典链优先（ExplorerPatcher 恢复经典任务栏时自动走 Win10 链）；UIA 是跨进程 COM 调用可能阻塞，独立成线程以免装低级钩子的线程被卡、钩子超时被系统摘除。全屏应用或任务栏隐藏时自动隐藏覆盖层，explorer 重启后自动恢复。
- 弹窗常驻渲染：窗口"隐藏"时停放在屏幕外 (32000,32000)（winit 对隐藏窗口不派发重绘，事件循环会停摆，离屏方案绕开此限制）。
- 渲染：GDI+ 双缓冲 + UpdateLayeredWindow 分层窗口（无 GPU 框架，锁屏/远程会话均可运行）。
- **DPI 感知**：进程声明 Per-Monitor V2（老系统回退 System Aware），窗口矩形 / 低级鼠标钩子 / UIA / 光标坐标恒为物理像素且实时反映当前缩放——改屏幕缩放不会出现坐标系错位（System Aware 下坐标滞留在登录时的 DPI，缩放后点击时钟会穿透给系统日历）。主面板定时器轮询 shcore!GetDpiForMonitor，发现缩放变化即按新系数全局重建/重摆全部窗口（`gdi::set_scale` + 各窗口位图惰性重建 + 主面板 `SetWindowRgn` 命中区域重建，否则日历被创建时的旧区域裁剪显示不全）。已知限制：多显示器不同缩放时按主屏系数绘制，副屏由 DWM 缩放；内存位图上的 GDI+ 文本一律灰度抗锯齿（ClearType 在 Graphics-from-bitmap 上被 GDI+ 静默回退）。
- **内存压缩**：各分层窗口的后台位图（合计约 5MB @100% 缩放，高 DPI 下更大）不再常驻——隐藏时整体释放、显示时惰性重建（`gdi::alloc_dib/free_dib`；DIBSection 句柄记录在 Ui 结构里，避免每次循环泄漏 GDI 句柄），设置/天气/新建弹窗等次窗口创建时也不分配。隐藏态提交内存从 ~16MB 降到 ~4MB；工作集修剪（SetProcessWorkingSetSize + HeapCompact，空闲时降频）沿用。
- **点击外部关闭**：点击软件自身弹窗（设置、天气侧栏等，均为 NOACTIVATE 窗口且 `WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE`）不会关闭日历；只有点击发生在软件相关窗口之外（其他应用/桌面，日历失焦）时才关闭；光标位于软件弹窗之上时的失焦同样保持显示（双保险）。
- 配色取自设计图：背景 `#202838`、强调蓝 `#3E87FA`、周末红 `#E54B4B`。
- 调试钩子（环境变量）：`CAL_PAGE=agenda|settings`、`CAL_SETTINGS=1` 指定起始页面，`CAL_YM=2026-10` 指定起始月份，`CAL_FAKE_WX=1` 使用离线假天气数据，`CAL_SIDEBAR=1` 弹出日历时自动打开日期侧边栏，`CAL_SF=1.25/1.5/2` 强制缩放系数（覆盖时缩放轮询停用，在 100% 缩放的机器上验证高 DPI 布局），`CAL_TEXT_HINT=0~5` 覆盖 GDI+ 文本渲染模式，`CAL_UIA_LOG=1` 把 Win11 时钟 UIA 定位的每轮扫描结果写到 `%APPDATA%\z-calendar\uia.log`，`CAL_DUMP=x.bmp` / `CAL_DUMP2=x.bmp` / `CAL_DUMP3=x.bmp` / `CAL_DUMP4=x.bmp` 保存日历/设置窗/天气面板/日期侧栏首帧，`CAL_DUMP_EXIT=1` 退出时转储状态。
